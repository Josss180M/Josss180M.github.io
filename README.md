# Josss180M.github.io

Portafolio personal de Joshue Moreno, publicado con GitHub Pages.

Sitio estático (`index.html`), sin build step. Para editarlo, modificar
`index.html` y las imágenes en `assets/img/`, luego hacer commit y push
a `main` — GitHub Pages lo publica automáticamente.
